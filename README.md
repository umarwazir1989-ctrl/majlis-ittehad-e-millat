# مجلس اتحادِ ملت — اردو ویب سائٹ

یہ Next.js پر تیار کردہ ابتدائی ڈمی ہوم پیج ہے۔

## چلانے کا طریقہ

```bash
npm install
npm run dev
```

پھر براؤزر میں `http://localhost:3000` کھولیں۔

## موجودہ خصوصیات
- مکمل اردو RTL لے آؤٹ
- موبائل ریسپانسیو ڈیزائن
- تعارف، اقدار، تنظیمی ڈھانچہ، شخصیات، سرگرمیاں اور رابطہ
- تمام نام اور رابطہ معلومات فی الحال ڈمی ہیں
